# Fog Texture

`fog.png` and `fogcolors.png` are the particle texture and colour range of
the Fuel model **Fog Emitter** (owner OpenRobotics, version 5, author Carlos
Agüero, <https://fuel.gazebosim.org/1.0/openrobotics/models/fog%20emitter>),
licensed under Creative Commons Attribution 4.0 International
(<https://creativecommons.org/licenses/by/4.0/>), unchanged.

`tools/smoke_rig.py` gives them to Gazebo's ParticleEmitter for the
comparison its `particles=` levels make (roadmap item 18 stage 1).
